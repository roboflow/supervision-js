# Pedestrian Paths Fixture

This fixture demonstrates semantic person detections and open polyline paths.
It is authored offline and is never regenerated by the demo, docs, browser
package, or test suite.

`people-walking.webm` is the unmodified downloaded media. The source page
describes a static low-angle pedestrian scene with people passing close to the
camera. CC0 permits its redistribution in this repository.

## Frozen Inputs And Derivations

`raw-yolov8n-640.jsonl` preserves every response from local Roboflow
Inference. The header records the source, model, and tool provenance; it does
not contain API keys or source-frame image payloads.

| Input | Pinned value |
| --- | --- |
| Inference image | `roboflow/roboflow-inference-server-cpu@sha256:35d04faf0f9ba17542fc4c3f998951858aa8f13f59ebdaeeb79318eb096fa7a3` |
| Inference API | `1.3.9` |
| Fixture generator commit | `6b379f675fc31aaf63c87de0890d65f56f65960d` |
| Model alias | `yolov8n-640` (`coco/3`) |
| Model weights SHA-256 | `5af3f169e67aaf17470193823a5f86f1fd4124a81ca6a2132a42ce86343ce67d` |
| Model license | [AGPL-3.0](https://github.com/ultralytics/ultralytics/blob/main/LICENSE) |
| Inference request | person class only; confidence 0.25; IoU 0.3; 375 source frames at their recorded 25 fps PTS |
| Tracker | `trackers` 2.4.0, Apache-2.0; `supervision` 0.29.1, MIT |
| Tracker policy | ByteTrack, activation/high confidence 0.25, minimum two consecutive frames, IoU 0.1, lost buffer 30 |
| Polyline derivation | `byte-track-center-trace-v1`: last 2.0 s / 50 center-rect points for each confirmed track |

The model output does **not** contain polylines. `bytetrack-associations.jsonl`
records the named deterministic association pass. `detections.json` then adds a
time-bounded `polyline` only for each confirmed tracker id, while preserving
the original semantic rect and class. This makes the visualization honest:
paths are derived tracking data, not presented as detector output.

## Regeneration

Run these one-time commands from the repository root. The server must be
loopback-only; `run.py` rejects any other endpoint.

```bash
python tools/inference-fixture/run.py \
  --server http://127.0.0.1:9001 \
  --source demo/fixtures/people_walking_detection_v1/people-walking.webm \
  --output demo/fixtures/people_walking_detection_v1/raw-yolov8n-640.jsonl \
  --model yolov8n-640 \
  --model-license AGPL-3.0 \
  --model-weights-sha256 5af3f169e67aaf17470193823a5f86f1fd4124a81ca6a2132a42ce86343ce67d \
  --inference-image-digest sha256:35d04faf0f9ba17542fc4c3f998951858aa8f13f59ebdaeeb79318eb096fa7a3 \
  --confidence 0.25 \
  --iou-threshold 0.3 \
  --class-filter person

docker run --rm --entrypoint python \
  -v "$PWD:/workspace" -w /workspace \
  roboflow/roboflow-inference-server-cpu@sha256:35d04faf0f9ba17542fc4c3f998951858aa8f13f59ebdaeeb79318eb096fa7a3 \
  tools/inference-fixture/track.py \
  --input demo/fixtures/people_walking_detection_v1/raw-yolov8n-640.jsonl \
  --output demo/fixtures/people_walking_detection_v1/bytetrack-associations.jsonl \
  --frame-rate 25 \
  --track-activation-threshold 0.25 \
  --high-confidence-threshold 0.25 \
  --minimum-consecutive-frames 2 \
  --minimum-iou-threshold 0.1 \
  --lost-track-buffer 30

npm run fixture:inference:create
node tools/sam3-fixture/chunk-detections.mjs \
  --input demo/fixtures/people_walking_detection_v1/detections.json \
  --fixture-dir demo/fixtures/people_walking_detection_v1 \
  --dataset-id people_walking_detection_v1 \
  --compact
```

The final normalized artifact is checked against the raw source and tracker
provenance by repository tests. No network or inference service is used at
runtime.
